# Cemu Barista Motion

This experimental Linux x86_64 build adds motion-sensor support for a physical
Wii U GamePad connected through Barista. The tested pitch, roll, and yaw
calibration is enabled by default.

## Install

1. Download the `x86_64.AppImage` asset below.
2. Make it executable: `chmod +x Cemu-Barista-Motion-*-x86_64.AppImage`
3. Open Barista and connect the Wii U GamePad.
4. Run the AppImage as your normal desktop user.

Barista is installed separately. See
[BARISTA_MOTION.md](https://github.com/Nerostalgeek/Cemu-Barista-Motion/blob/main/BARISTA_MOTION.md)
for configuration, calibration variables, troubleshooting, and current
limitations.

The `.sha256` asset can be used to verify the download.
